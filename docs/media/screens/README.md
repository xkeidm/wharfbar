# README screenshots

Real captures of WharfBar on Windows 11 (1920×1080, 100% DPI) over the bundled
**Pier Horizon** wallpaper pair. Other windows are minimised and the desktop-icon
layer is kept out of the shot; every change was restored after the session.

- `en/` — English UI, used by [`README.md`](../../../README.md)
- `tr/` — Turkish UI, used by [`README.tr.md`](../../../README.tr.md)

Each set contains:

| File | Content |
|------|---------|
| `hero-{dark,light}.jpg` | Full desktop (1600×900, JPG q90): top bar, island, dock and wallpaper |
| `dock-{dark,light}.png` | Bottom-centre dock over the wallpaper |
| `island-{dark,light}.png` | Island pill with the island's **Wallpaper** gallery open |
| `quick-settings-{dark,light}.png` | Right side of the top bar with the Quick settings flyout |
| `settings-{dark,light}.png` | Settings → **Appearance** window |

The light shots use `pier-horizon-light.jpg`, the partner WharfBar's theme sync
applies when the app theme changes to light. The English island shot was taken
with the island's **Color** tab hidden (`island.colorPickerTab=false`) so the
tab strip fits the English labels without the overflow fade.
